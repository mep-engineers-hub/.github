# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **private vulnerability reporting** on the affected repo ("Security" tab > "Report a vulnerability"). The repo owner and the organization maintainer will reply.

## Scope

Code in this organization's repos. For third-party tools listed in awesome-mep, report to that tool's own project.

## Safety-relevant errors

A calculation error is not a security issue, but it matters. Open an issue labelled `calc-error` with the input, the expected result, the source of the expected result (document, edition, clause # or worked example), and the tool's output.
