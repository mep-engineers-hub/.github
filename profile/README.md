# MEP Engineers Hub

> **Unverified. Not for stamped or issued work. Check against the adopted code edition.**

A community of practicing mechanical and MEP engineers who share the tools, scripts and workflows they actually use, and say honestly how well they work.

## What is here

- **[awesome-mep](https://github.com/mep-engineers-hub/awesome-mep)**: an annotated index of MEP software tools. Each entry records who tested it, how, and against which worked example.
- **Member tool repos**: small tools written by members. Each repo has its own owner and license (MIT by default).
- **[Discussions](https://github.com/mep-engineers-hub/awesome-mep/discussions)**: questions, code clarifications, "has anyone used X?", show and tell, ideas.

## Index tiers

| Tier | Meaning |
| --- | --- |
| Found | Listed from public information. Nobody here has run it yet. |
| Tried | A member installed and ran it on a realistic case and wrote down what happened. |
| Validated against a worked example | A member reproduced a published worked example with it and linked the comparison. |

"Validated" means the tool reproduced one worked example. It never means code-compliant, certified or approved for design.

## Ground rules

1. **No standards content.** No tables, figures, excerpts or PDFs from ASHRAE, NFPA, CIBSE, IPC/IMC, UAE or any other paid code or standard. Cite the document, edition and clause (#) only. Users enter the values themselves.
2. **No project data.** No client names, drawings, project references or site data, in repos, Discussions or chat.
3. **Every repo carries the banner** shown at the top of this page.
4. **Licenses.** Code is MIT by default. The index and docs are CC BY 4.0. The index flags GPL/AGPL and unlicensed tools.
5. **Be useful and respectful.** See the [Code of Conduct](https://github.com/mep-engineers-hub/.github/blob/main/CODE_OF_CONDUCT.md).

## How to contribute

Read [CONTRIBUTING](https://github.com/mep-engineers-hub/.github/blob/main/CONTRIBUTING.md). In short: shared repos change by pull request plus one review; each member tool repo is run by the member who created it; anyone can fork. To join, ask a member to open a Join request.

See also the [DISCLAIMER](https://github.com/mep-engineers-hub/.github/blob/main/DISCLAIMER.md).
